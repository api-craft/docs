# OpenAPI & Swagger Integration

API Craft supports automatic generation of OpenAPI (Swagger) documentation.

- Generate Swagger docs from your routes  
- Serve interactive Swagger UI with your API  
- Customize API metadata and schemas  
- Export OpenAPI JSON/YAML for external tools  

Use these features to document and share your API seamlessly.
