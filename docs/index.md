# API Craft Ecosystem

Welcome to the official documentation for the **API Craft Ecosystem** — a modular, developer-friendly toolkit designed to accelerate API development for Node.js/Express applications.

Whether you're building a simple REST API or a complex backend service, API Craft provides CLI tooling, plug-and-play routing, powerful CRUD scaffolding, and developer ergonomics that reduce boilerplate and let you focus on your business logic.

## NPM Packages

**API Craft** includes two primary packages:

- [`@tselven/api-craft`](https://www.npmjs.com/package/@tselven/api-craft) – A fast, pluggable Express-based API generator.
- [`@api-craft/crud-router`](https://www.npmjs.com/package/@api-craft/crud-router) – A smart CRUD routing layer that auto-generates RESTful routes for your models.

Both packages are maintained together under the `api-craft` ecosystem.
