# API Craft

Welcome to the official documentation for **API Craft** and **CRUD Router**, two powerful NPM packages designed to simplify your API and CRUD development.

- `@tselven/api-craft`: Super fast, pluggable API generator for Node.js/Express apps.
- `@api-craft/crud-router`: Smart and clean CRUD router layer that saves hours of boilerplate.
---

## Getting Started

Install both packages via npm or yarn:

```bash
npx create-api-craft [project name]
```
